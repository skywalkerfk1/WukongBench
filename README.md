# WukongBench
Wukong Benchmark for internship

Консольное приложение на C# (.NET) для автоматического прогона бенчмарков Black Myth: Wukong Benchmark Tool с целью тестирования производительности процессора (CPU) и видеокарты (GPU).

Инструмент полностью автоматизирует процесс: от изменения настроек конфигурации и запуска через Steam до имитации кликов мыши, сбора данных о системе, парсинга результатов и закрытия приложения.

Основные возможности
Два режима тестирования:

CPU-тест: низкие настройки графики (Low, 720p) для создания минимальной нагрузки на видеокарту и максимального упора на процессор.

GPU-тест: максимальные настройки графики (Cinematic, 1440p) для максимальной нагрузки на видеокарту.

Автоматизация через Steam: запуск бенчмарка по его официальному AppID (3132990).

Эмуляция кликов: автоматический проход по меню и запуск теста без участия пользователя.

Парсинг логов: автоматическое чтение JSON-логов бенчмарка (без расширений) для извлечения характеристик системы (CPU, GPU, RAM) и результатов производительности (FPSAvg, FPSMin).

Безопасное завершение: ожидание окончания работы теста (до 5 минут) с последующим автозакрытием процесса.

Требования для запуска
Установленная игра/инструмент Black Myth: Wukong Benchmark Tool в Steam.

Установленная платформа .NET (рекомендуется .NET 8.0 или выше).

Запущенный клиент Steam.
